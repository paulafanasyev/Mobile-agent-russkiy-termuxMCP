# Claude в проекте

`CLAUDE.md` не является менеджером файлов или отдельным runtime-модулем. Это набор инструкций для Claude Code.

В проекте он работает вместе с:

- `AGENTS.md` — общие правила для всех AI-агентов;
- `CLAUDE.md` — правила Claude Code;
- `.claude/settings.json` — настройки Claude-specific интеграции;
- общим Agent Orchestrator — будущая единая точка выполнения инструментов приложения.

## Правило архитектуры

Claude не должен получать обходной неограниченный доступ к Android. Его действия должны проходить через те же политики, разрешения, MCP/TermuxMCP и native-инструменты, что и Светлана и другие агенты.

## Native Android

Claude может помогать разрабатывать native-слой, но наличие `CLAUDE.md` не означает, что код автоматически выполняется на телефоне. Реальная функциональность подтверждается сборкой и runtime-тестом.
