# Локальный фаервол Mobile Agent

Модуль предоставляет безопасный слой сетевой защиты для Android-агента.

## Уровни

1. **VPN allowlist** — системный `VpnService` и список разрешённых приложений.
2. **Политика** — правила по приложению, домену, протоколу и порту.
3. **Журнал** — события разрешения и блокировки.
4. **Профили** — обычный, строгий и режим только разрешённых приложений.
5. **Kill Switch** — политика запрещения трафика при отсутствии разрешённого состояния.

## Важное ограничение

`VpnService.Builder.establish()` предоставляет файловый дескриптор IP-пакетов. Для полноценного режима проксирования необходимо обрабатывать исходящие пакеты и возвращать допустимые входящие пакеты. Поэтому текущий код намеренно не заявляет полноценное проксирование: это следующий нативный слой packet-processing.

Android позволяет приложению использовать `addAllowedApplication()` для per-app VPN. Приложение не должно выдавать пользователю ложное сообщение о том, что произвольный `blocklist` уже работает.

## Безопасность

- не хранить API-ключи в правилах фаервола;
- не разрешать MCP произвольно отключать защиту без политики подтверждения;
- чувствительные изменения должны фиксироваться в журнале;
- пользователь должен явно подтвердить первый запуск VPN через системный Android-диалог.
