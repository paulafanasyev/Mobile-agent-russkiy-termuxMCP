# CLAUDE.md — инструкции Claude Code

Полные правила проекта находятся в `AGENTS.md`. Этот файл является входной точкой для Claude Code.

## Обязательно

Перед изменением кода прочитать `AGENTS.md`.

Проект **Mobile Agent Русский TermuxMCP**: русскоязычный мобильный ИИ-агент для Android с локальным/облачным ИИ, Светланой, MCP/TermuxMCP, памятью, навыками, планировщиком, документами и Firewall/VPN на базе libbox.

### Правила работы

1. Не выдавать каркас или заглушку за готовую функцию.
2. После существенного изменения запускать соответствующие проверки.
3. Не ломать `pnpm-lock.yaml` для обхода проблем зависимостей.
4. Не использовать `git push --force` в `main`.
5. Не коммитить API-ключи, токены или другие секреты.
6. Все пользовательские тексты и новая документация — на русском языке, кроме технических идентификаторов.
7. Не давать агенту неограниченный shell-доступ: действия выполняются через контролируемые инструменты и политики разрешений.
8. Для опасных или необратимых операций требуется подтверждение пользователя либо заранее заданная пользователем политика.
9. `/loop` должен иметь ограничение и возможность остановки.
10. `libbox.aar` является воспроизводимым артефактом и не должен храниться в Git.
11. Firewall не считается работающим до успешной инициализации настоящего libbox.
12. Bridge `VpnService → libbox` должен использовать реальный API собранного AAR, а не имитацию forwarding.

## Перед разработкой

- Проверить версию Expo в `package.json`.
- Для Expo использовать соответствующую официальную документацию.
- Изучить существующую архитектуру перед созданием нового модуля.
- Переиспользовать существующие MCP/skills/scheduler/memory механизмы, если они подходят.

## Перед завершением этапа

По возможности выполнить:

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm exec tsc --noEmit
bash scripts/verify-android-agent.sh
```

Для Android/native-изменений дополнительно использовать CI с Android SDK/NDK и проверять реальный runtime.

## Статусы функций

В отчётах всегда различать:

- **Проверено** — реально выполнено и проверено;
- **Реализовано, требует runtime-проверки**;
- **Каркас** — код подготовлен, но функция ещё не подключена полностью;
- **Не реализовано**.

Не использовать слово «готово» для неподтверждённого runtime.
