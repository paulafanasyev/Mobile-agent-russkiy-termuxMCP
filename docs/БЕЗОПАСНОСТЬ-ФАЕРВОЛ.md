# Фаервол Mobile Agent

## Что добавлено сейчас

В приложение добавлен нативный Android-модуль фаервола на базе `VpnService`.

Первый этап использует строгий режим `allowlist`: только приложения, перечисленные в списке разрешённых пакетов, направляются в локальный VPN-интерфейс. VPN-сервис намеренно не пересылает пакеты дальше, поэтому этот режим является безопасным контуром блокировки по умолчанию для выбранных приложений.

Перед запуском Android показывает системное подтверждение VPN. Приложение не может скрыто получить это разрешение.

## Почему пока нет режима blocklist

Настоящая схема «разрешить всем, кроме выбранных приложений» требует полноценного packet-processing backend. Простое использование `addDisallowedApplication()` не блокирует приложение — Android выводит его трафик мимо VPN. Поэтому такой режим пока не объявляется реализованным.

## Безопасность агента

Светлана не должна иметь скрытого права отключить защиту. Отключение фаервола будет отдельным чувствительным действием с подтверждением пользователя и записью в журнал аудита.

API-ключи не относятся к правилам фаервола и должны храниться в защищённом хранилище устройства, а не в репозитории.
